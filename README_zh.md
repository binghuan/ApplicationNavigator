# Apps Navigator (应用导航)

一款轻量级的 Android 实用工具应用，旨在帮助用户管理已安装的应用程序并高效监控与隐私相关的权限。

## 📱 主要功能

*   **应用管理**：列出设备上所有已安装的应用程序及其版本和图标。
*   **快速启动**：直接从列表中轻松启动任何已安装的应用程序。
*   **隐私仪表板**：根据应用程序请求的敏感权限对其进行分类，让您深入了解哪些应用程序访问了您的：
    *   位置服务 (LBS)
    *   通讯录 (Contacts)
    *   日历 (Calendars)
    *   提醒事项 (Reminders)
    *   SD 卡 / 存储 (Storage)
    *   蓝牙共享 (Bluetooth)
*   **进程监控**：显示前台和后台进程的相关信息。
*   **广告集成**：集成 AdMob 广告服务。

## 🛠 技术栈

*   **编程语言**: Java
*   **最低 SDK 版本**: API 24 (Android 7.0 Nougat)
*   **目标 SDK 版本**: API 34 (Android 14)
*   **构建系统**: Gradle 8.13
*   **依赖库**:
    *   AndroidX (AppCompat, RecyclerView, CardView, Material)
    *   Google Play Services (Ads)

## 🚀 快速开始

###先决条件

*   Android Studio (建议使用最新版本)
*   JDK 17 (Gradle 8.x 需要)
*   运行 API 级别 24 或更高版本的 Android 设备或模拟器。

### 安装步骤

1.  **克隆仓库：**
    ```bash
    git clone https://github.com/binghuan/ApplicationNavigator.git
    ```

2.  **在 Android Studio 中打开：**
    *   启动 Android Studio。
    *   选择 "Open" (打开) 并导航到克隆的目录。

3.  **构建项目：**
    *   等待 Gradle 同步项目依赖项。
    *   通过 `Build > Make Project` 构建项目。

4.  **运行应用：**
    *   连接您的 Android 设备或启动模拟器。
    *   点击工具栏中的 "Run" 按钮（绿色播放图标）。

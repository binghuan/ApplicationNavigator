# Apps Navigator

A lightweight Android utility application designed to help users navigate their installed apps and monitor privacy-related permissions efficiently.

## 📱 Features

*   **App Management**: Lists all installed applications on your device with their versions and icons.
*   **Quick Launch**: Easily launch any installed application directly from the list.
*   **Privacy Dashboard**: Categorizes applications based on sensitive permissions they request, giving you insight into which apps access your:
    *   Location Services
    *   Contacts
    *   Calendars
    *   Reminders
    *   SD Card / Storage
    *   Bluetooth Sharing
*   **Process Monitoring**: Displays information about foreground and background processes.
*   **Ad Integration**: Includes AdMob integration.

## 🛠 Tech Stack

*   **Language**: Java
*   **Minimum SDK**: API 24 (Android 7.0 Nougat)
*   **Target SDK**: API 34 (Android 14)
*   **Build System**: Gradle 8.13
*   **Libraries**:
    *   AndroidX (AppCompat, RecyclerView, CardView, Material)
    *   Google Play Services (Ads)

## 🚀 Getting Started

### Prerequisites

*   Android Studio (Latest version recommended)
*   JDK 17 (Required for Gradle 8.x)
*   Android device or emulator running API level 24 or higher.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/binghuan/ApplicationNavigator.git
    ```

2.  **Open in Android Studio:**
    *   Launch Android Studio.
    *   Select "Open" and navigate to the cloned directory.

3.  **Build the project:**
    *   Let Gradle sync the project dependencies.
    *   Build the project via `Build > Make Project`.

4.  **Run the app:**
    *   Connect your Android device or start an emulator.
    *   Click the "Run" button (green play icon) in the toolbar.
